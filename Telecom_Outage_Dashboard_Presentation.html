INFRASTRUCTURE AS CODE

Ansible Provisioning & Automated Rollbacks

Idempotent Host Configuration and Zero-Downtime Application Lifecycle

Modular Ansible Role

Separation of concerns using `roles/telecom_app/` with dedicated `tasks/`, `handlers/`, `defaults/`, and `templates/`.

Strict Idempotency

Re-running `ansible-playbook ansible/playbook.yml` detects unchanged configuration and results in `changed=0, failed=0`.

Post-Deploy Health Check

Utilizes Ansible `uri` module to poll `http://localhost:8085/api/health` before confirming deployment success.

Instant Rollback Playbook

Automated `ansible/rollback.yml` restores the previous stable release artifact within 10 seconds if health checks fail.
